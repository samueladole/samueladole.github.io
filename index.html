Selected projects

  • In progress — 2026

    Real-time observability & evaluation platform for RAG systems

    MSc Data Science dissertation — Leeds Beckett University

    A framework-agnostic RAG platform in Python 3.12 built to bring production tracing and monitoring practice to LLM pipelines. The retrieval layer fuses dense and sparse search — ChromaDB (HNSW, cosine, 384-dim all-MiniLM-L6-v2 embeddings) combined with BM25Okapi through a custom Reciprocal Rank Fusion layer (k=60, 0.6 dense / 0.4 sparse) — without pulling in a retrieval framework.

    Quality is scored automatically with RAGAS 0.4 (context relevance, faithfulness, answer correctness) using Qwen2.5 7B as a fixed third-model-family judge, surfaced as live per-query metrics rather than batch-scored after the fact. After evaluating LangSmith, Arize Phoenix, TruLens and OpenTelemetry's LLM extensions, I built custom instrumentation: a perf_counter timer across four stages — embed, retrieve, generate, evaluate — writing one orjson document per query with token counts reconciled against tiktoken. That decomposition showed RAGAS evaluation alone accounts for 85.7% of end-to-end latency.
